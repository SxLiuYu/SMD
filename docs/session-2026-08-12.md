### 2.3 小红书发布 — ✅ 成功
- **工具**: Playwright 无头 Chromium + CDP shadow DOM piercing
- **流程**: 
  1. Playwright `set_input_files` 上传封面 → 触发 React onChange
  2. 等待图片上传到 CDN（blob: → xhscdn.com，**不等待会存草稿**）
  3. 删除遮罩层（hover-mask 拦截点击）
  4. nativeInputValueSetter 填标题
  5. execCommand('insertText') 填正文
  6. CDP `DOM.getDocument({pierce:true})` 找 shadow DOM 内 `button.ce-btn.bg-red`
  7. `DOM.resolveNode` + `Runtime.callFunctionOn(this.click())` 点击发布
  8. 拦截 `POST /web_api/sns/v2/note` 响应，`success:true` 即成功
- **关键发现**: 小红书发布成功后页面不一定跳 `success` 页，但 API 返回 `success:true` 就表示发布成功

## 3. ESP32 固件修复

### 3.1 硬件连不上
- **问题**: ESP32 提示"检查新版本失败"，OTA 地址 `192.168.1.3:8000/xiaozhi/ota` 连不上
- **根因**: voice_server.py 的 OTA 端点返回 `localhost` 而非 LAN IP
- **修复**: 检测客户端 IP，非 127. 开头则返回 `_get_lan_ip()`（192.168.1.12）
- **文件**: `charlie/voice_server.py` — 新增 `_get_lan_ip()` + `_read_tunnel_url()` 

### 3.2 屏幕不亮
- **问题**: 用 xz 项目（xingzhi-cube-1.54tft-wifi 板子）编译的固件屏幕不亮
- **根因**: xingzhi-cube 和 lc-s3 的显示引脚映射不同
- **修复**: 恢复 `firmware/flash_16MB_local.bin`（从原厂固件 patch 来，显示引脚正确）
- **最终固件**: 16MB 全量 flash, OTA→192.168.1.3, WS→ws://192.168.1.3:8000/ws/xiaozhi

### 3.3 IP 别名
- **问题**: 固件 OTA 地址是 192.168.1.3，Mac 实际 IP 是 192.168.1.12
- **修复**: `sudo ifconfig en1 alias 192.168.1.3 255.255.255.0` + `sudo route add -host 192.168.1.3 -interface lo0`
- **脚本**: `scripts/esp32-alias.sh`

## 5. 决策引擎修复 — 9点提醒刷屏
